

新增 replace.html 全局替换页。模式与匹配优先级沿用有序 NFA；原文 ASCII、2000 字符，模式 120 字符，模板 2000 字符。支持 $$、$&、$`、$'、$1～$8；不存在的组编号保留字面量，未参与的已存在组替换为空。所有范围、前后缀和捕获始终引用原文；非重叠匹配中零长度命中后仅推进搜索一个字符，末尾也可命中一次，不丢弃未匹配文本。显示范围证据与下载必须属于同次结果。

替换实现见 replacement.js；可复验用例 `node test-replace.js`：固定边界用例对照原生 String.replace、1500 组随机 fuzz 以 index.html 自带的有序回溯解释器 + 经典 ES 全局循环为权威基准（逐项核对整体区间与每个捕获，null=未参与、[x,x)=真空捕获）、1080 组简单模式与浏览器逐字节对照，并用 jsdom 真实执行 replace.html 核对页面文本、证据表与下载 Blob 字节为同一次结果。
